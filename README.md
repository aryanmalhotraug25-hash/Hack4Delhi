🗳️ Voter Education & Awareness Platform (Polaris)

A neutral, interactive, and educational web platform designed to help citizens understand elections in India, with a special focus on One Nation, One Election (ONOE).
Built to combat misinformation, improve voter literacy, and demonstrate democratic processes in a simple, engaging way.

🌟 Project Vision

Elections are the backbone of democracy, yet misinformation and complexity often discourage informed participation.
This platform aims to:

Educate voters using verified facts

Bust myths around One Nation, One Election

Demonstrate voting processes interactively

Present data-driven insights on election costs and governance impact

🚀 Key Features
🎓 Learn About Elections

Swipe-based educational cards (Swiper.js)

Covers historical background, expert recommendations, and governance impact

🔊 Multilingual + Audio Support

English ↔ Hindi toggle

Pre-recorded audio summaries for accessibility

Instant stop/play logic when language changes

🧠 Myth vs Reality (Comic Section)

Interactive comic explaining ONOE misconceptions

Encourages critical thinking in a visual format

🗳️ Demo Voting Experience

Simulated EVM + VVPAT voting

Demonstrates how simultaneous elections can be conducted

📊 Impact & Data Visualization

Cost comparison: Separate vs Simultaneous Elections

Donut chart for Election Expenditure Breakdown

Highlights what saved public money could build (hospitals, schools, roads)

🚧 Challenges & Solutions Section

Real-world crisis scenarios (govt collapse, logistics, voter behavior)

Click-to-reveal policy-backed solutions

🤖 LokGyan AI (Chatbot)

AI assistant trained on official and verified sources

Helps users ask election-related questions

🛠️ Tech Stack

HTML5 – Structure

CSS3 – Styling & responsiveness

JavaScript (Vanilla) – Interactivity & logic

Swiper.js – Card slider

Chart.js – Data visualizations

Botpress – AI chatbot integration

Google Fonts (Montserrat) – Typography
