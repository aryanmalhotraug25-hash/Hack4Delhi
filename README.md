Voter Education & Awareness Platform – One Nation One Election
A voter awareness web platform that explains elections and the One Nation One Election (ONOE) concept in a neutral, simple, and interactive way.
​

The platform helps citizens:

Learn key facts about simultaneous elections and Indian electoral processes.
​

Experience a dual EVM + VVPAT demo vote simulation for Lok Sabha and Vidhan Sabha.
​

Explore verified information, myths, and FAQs through an educational interface.
​

Features
Neutral voter education content

Simple explanations about parliamentary reports, Law Commission recommendations, and the High Level Committee on simultaneous elections.
​

Focus on governance efficiency, national interest, and historical context of simultaneous elections.
​

Interactive dual EVM + VVPAT simulation

Lok Sabha EVM with sample candidates and parties.
​

Vidhan Sabha EVM locked until Lok Sabha vote is cast, mirroring real-world sequencing.
​

VVPAT panes to conceptually show how votes are recorded.
​

Clearly marked as an educational simulation only.
​

Myth & misinformation verification section

Dedicated “Verify” section to address misconceptions around elections and ONOE.
​

LokGyan AI assistant (concept)

“Ask AI” section designed as LokGyan AI, described as being trained on official and verified sources like the Election Commission of India and Government reports.
​

Responsive, static web app

Deployed as a static site on Netlify for easy access and sharing.
​

Tech Stack
Frontend: HTML, CSS, JavaScript

Simulation UI: Custom JS logic for EVM + VVPAT flow and state handling.
​

Deployment: Netlify (link: https://hack4delhi-onoe.netlify.app/)
